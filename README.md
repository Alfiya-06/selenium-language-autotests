# selenium-language-autotests
# Автоматизированное многоязычное тестирование на Selenium & Pytest

Финальный проект по автоматизации, демонстрирующий запуск UI-тестов с динамическим выбором языка пользователя через аргументы командной строки с использованием Selenium WebDriver и PyTest.

## 🛠 Структура проекта
- `conftest.py` — Фикстуры и настройка параметров командной строки (`--language`).
- `test_items.py` — Тест, проверяющий наличие уникальной кнопки добавления в корзину на странице товара.
